### Formats de fichiers

- `.stl` - utilisé pour l’impression 3D.
- `.stp` - utilisé pour modifier l’assemblage dans des programmes CAD (Fusion 360, FreeCAD, etc.).

### Utilisation

1. Ouvrez [`iHeater.stp`](../../CAD/iHeater.stp) dans votre programme CAD pour examiner l’assemblage complet.
2. Chargez les fichiers STL dans votre slicer pour préparer l’impression 3D.
3. Assurez-vous que l’échelle sélectionnée lors de l’importation est **millimètres (mm)**.

### Matériau d’impression du boîtier

Matériaux recommandés :

* ABS, ABS-CF
* PA, PA-GF
* PP, PP-GF
* autres matériaux supportant 90C

### Remarques

- Assurez-vous que les ouvertures de ventilation ne sont pas obstruées lors de l’installation.
- Les fichiers STL sont optimisés pour une impression sans supports.
