# 3D列印機熱室加熱

## 1. 檢查風扇和通風孔

* 新型列印機通常配備排出熱空氣的風扇。在開始使用前，確保當腔室溫度超過設定值時，風扇不會自動啟動。
* 檢查列印機機殼中的縫隙和門周圍
* 檢查機殼的通風孔。如果熱室與電子元件區域相連，且存在未密封的開口，必須進行密封：

    * 使用普通膠帶
    * 鋁箔膠帶（更好地反射熱量）
    * 或使用隔熱材料（最佳方案）
* 這是為了防止控制電子元件過熱。


## 2. 熱源：列印機平台

* 熱床是腔室的主要熱源。
* iHeater本身通常無法在沒有熱床的情況下達到所需溫度。
* 如果需要在不開啟熱床的情況下加熱列印機腔室，請使用功率為600W-1kW的商用加熱器來補償熱床缺失的熱量（**需要檢查電氣安全性和電源線路的負載能力**）。

## 3. 使用輔助風扇

* 現代列印機通常在側壁上配有額外的風扇，用於吹動模型或安裝活性碳過濾器。
* 在腔室加熱階段，可以啟動這些風扇來混合空氣——這能加快和均勻化預熱。
* 最佳做法是設置宏邏輯：在開始加熱時啟動風扇，在達到目標溫度或開始打印後關閉風扇。

## 4. 何時開始列印

* 示例：目標腔室溫度為60°C。
* 可以在50-55°C時開始列印，因為啟動前有準備步驟：生成床面地圖、噴嘴預熱和清潔、首層鋪設。
* 這些過程需要幾分鐘；在此期間腔室會逐漸接近目標溫度。
* 打印前2-3mm後，腔室通常會達到並穩定在所需溫度，這對每台列印機是個別的。

## 5. 溫度傳感器安裝

* 溫度傳感器（熱敏電阻）應大約放在列印頭的高度。
* 它不應接觸列印機的任何機殼部件，否則會讀取部件溫度而不是空氣溫度。

## 6. 安全性和其他建議

* 放置iHeater時應確保氣流均勻，避免局部過熱。
* 使用機殼隔熱材料來減少熱損失。
* 加熱器電源線應能承受電流負載（電纜、連接器、保險絲）。
* 溫度設置應符合列印機機殼材料和操作環境條件。

## 7. 啟動前簡短檢查清單

* [ ] 風扇正常工作；通風孔清潔。
* [ ] 電子元件區域與熱腔室隔離。
* [ ] 已啟動額外的熱源。
* [ ] 混合空氣的風扇在預熱階段啟動。
* [ ] 溫度傳感器安裝在列印頭高度，不接觸機殼。
* [ ] 溫度限制和應急斷電已配置。
