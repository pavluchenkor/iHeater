# 3D打印机热室加热

## 1. 检查风扇和通风口

* 新型打印机通常配备了用于从仓室排出热空气的风扇。在开始使用前，请确保当仓室温度超过设定值时，风扇不会自动启动。
* 检查打印机外壳中的缝隙和门周围的缝隙
* 检查外壳通风口。如果热室与电子设备仓室接触，且有未关闭的通风孔，需要关闭它们：

    * 使用普通胶带；
    * 使用铝箔胶带（更好地反射热量）；
    * 或者使用隔热材料（最佳选项）。
* 这是为了防止控制电子设备过热。


## 2. 热源：打印机平台

* 热平台是仓室的主要热源。
* iHeater本身通常无法在没有热平台的情况下将温度升至所需水平。
* 如果需要在不启用热平台的情况下加热打印机体积，使用600W - 1kW功率的工厂生产的加热器来补偿平台热量不足（**必须进行电气安全检查和供电回路负载能力验证**）。

## 3. 使用辅助冷却风扇

* 现代打印机型号通常沿着侧壁配有额外的风扇，用于额外的模型冷却或室内的碳过滤器。
* 在室加热阶段，可以启动这些风扇来搅拌空气 - 这加速并均匀了加热过程。
* 最好的做法是配置宏逻辑：在加热启动时启动冷却风扇，在达到目标温度或开始打印初始层时关闭。

## 4. 何时开始打印

* 例如：目标仓室温度为60°C。
* 可以从50-55°C开始打印，因为在启动前有准备步骤：平台调平、加热并清洁喷嘴、铺设初始层。
* 这些过程需要几分钟；在此期间，仓室能够接近目标值。
* 打印完模型的前2-3毫米后，仓室通常达到所需温度并稳定，这个参数因每台打印机而异

## 5. 温度传感器安装

* 温度传感器（热敏电阻）应放置在大约打印头的高度。
* 它不应该接触打印机外壳的部件，否则会读取部件温度而不是空气温度。

## 6. 安全性和其他建议

* 放置iHeater时要确保气流均匀，避免局部过热。
* 应用外壳隔热材料来减少热量损失。
* 加热器电源线必须承受电流负载（电缆、连接器、保险丝）。
* 温度范围应符合打印机外壳材料和操作条件。

## 7. 启动前的简明检查清单

* [ ] 风扇正常工作；通风口已清洁。
* [ ] 电子设备仓室与热室隔离。
* [ ] 额外热源已启用。
* [ ] 空气循环冷却风扇在加热阶段启动。
* [ ] 温度传感器安装在打印头高度，不接触外壳。
* [ ] 温度限制和紧急关闭已配置。
